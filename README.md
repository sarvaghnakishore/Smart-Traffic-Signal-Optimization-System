## Tech Stack
- Next.js
- FastAPI
- MongoDB
- YOLOv8
- OpenCV

## Backend Run
```bash
cd backend
pip install -r requirements.txt
python run.py
```

## Frontend Run
```bash
cd frontend
npm install
npm run dev
```

## Open
Access the dashboard at: [http://localhost:3000/dashboard](http://localhost:3000/dashboard)
